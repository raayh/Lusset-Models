# Lusset Models – E-commerce de Moda

Loja virtual desenvolvida como projeto de TCC, com o objetivo de simular um e-commerce completo para venda de roupas. O projeto envolveu análise de mercado, modelagem de banco de dados, prototipação no Figma e desenvolvimento em React.js com funcionalidades reais de um fluxo de compras online.

## 🛍️ Funcionalidades Principais

* Login e cadastro de usuário
* Listagem de produtos por categoria (camisetas, calças, marcas)
* Carrinho de compras
* Etapas de pagamento e entrega

## 🔧 Tecnologias e Ferramentas Utilizadas

* React.js
* MySQL
* Node.js
* Figma
* VS Code, GitHub

## 🧪 Como Executar o Projeto (exemplo)

1. Clone o repositório:

   ```
   git clone https://github.com/raayh/LussetModels
   ```
2. Instale as dependências:

   ```
   npm install
   ```
3. Inicie o projeto:

   ```
   npm start
   ```
4. Acesse em:

   ```
   http://localhost:3000
   ```

## 📌 Observações

⚠️ Este projeto foi desenvolvido como parte de uma avaliação técnica em grupo, há 5 anos e, por isso, o banco de dados original não está mais disponível e alguns erros não foram concertados. Por isso, o projeto se encontra em revisão.
