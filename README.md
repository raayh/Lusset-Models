# Lusset Models – E-commerce de Moda

Projeto de um e-commerce completo para a loja fictícia **Lusset Models**, desenvolvido como Trabalho de Conclusão de Curso (TCC) no curso técnico em Tecnologia da Informação. O sistema foi construído com **React.js** e integrado a um **banco de dados relacional**, oferecendo funcionalidades para clientes e administradores.

## 🛍️ Funcionalidades Principais

### Para Usuários

* Página de login e cadastro
* Página inicial com destaques e categorias
* Navegação por páginas de produtos: camisetas, calças e marcas
* Detalhes do produto
* Fluxo de compra com:

  * Carrinho de compras
  * Página de pagamento
  * Seleção de entrega
* Página de perfil do usuário

### Para Administradores

* Acesso a painel administrativo
* Cadastro de novos produtos
* Visualização, edição e exclusão (CRUD) de produtos

## 🔧 Tecnologias Utilizadas

* **Front-end:** React.js
* **Back-end:** Integração com banco de dados relacional (ex: MySQL ou PostgreSQL)
* **Outras ferramentas:** HTML, CSS, bibliotecas de rotas e gerenciamento de estado

## 🎯 Objetivo do Projeto

Simular um e-commerce de moda funcional com foco na **experiência do usuário**, **organização das informações**, **fluxo de navegação claro** e uma **estrutura realista** tanto para o cliente quanto para o administrador do site.

## 🧪 Como Executar o Projeto (exemplo)

1. Clone o repositório:

   ```
   git clone https://github.com/raayh/LussetModels
   ```
2. Instale as dependências:

   ```
   npm install
   ```
3. Inicie o projeto:

   ```
   npm start
   ```
4. Acesse em:

   ```
   http://localhost:3000
   ```

> ⚠️ Certifique-se de ter o banco de dados configurado corretamente antes de iniciar a aplicação.

## 📌 Observações

⚠️ Este projeto foi desenvolvido como parte de uma avaliação técnica e, por isso, o banco de dados original não está mais disponível.
No entanto, o sistema foi estruturado com suporte a operações CRUD (Create, Read, Update, Delete), sendo possível adaptar a integração com um banco de dados relacional como MySQL ou PostgreSQL, conforme necessidade.

É possivel:

- Analisar a estrutura dos componentes no React.
- Recriar o banco de dados com base no formulário e na tabela de produtos disponíveis no código.
- Simular requisições com ferramentas como o JSON Server ou MockAPI.
